# IsNumber

Well tested 'is number' checks, that can accept number-like strings, and non-finite values as desired.

There are a lot of `is number` tests out there. Many of them don't work quite right. Others use a different
definition of `is number` than you might want. So after spending way too much time for such a simple thing,
here are four checks:

|Function        |number literals|number-like strings|Infinity and NaN|Infinity and NaN strings|other strings|
|----------------|---------------|-------------------|----------------|------------------------|-------------|
|isNumeric       |true           |true               |true            |true                    |false        |
|isNumber        |true           |false              |true            |false                   |false        |
|isFiniteNumeric |true           |true               |false           |false                   |false        |
|isFiniteNumber  |true           |false              |false           |false                   |false        |

A few notes on edge cases:

* **`BigInt` values return `false`**: Although `BigInt` values (e.g. `42n`) represent integers, all four functions return `false` for them. In JavaScript, `BigInt` cannot be mixed with `Number` in arithmetic (`42n + 1`), passed to `Math.*` functions, or serialized with `JSON.stringify` without throwing a `TypeError`. Additionally, `BigInt` values can exceed `Number.MAX_SAFE_INTEGER` (losing precision when coerced) or `Number.MAX_VALUE` (overflowing to `Infinity`).
* **Overflow strings return `false`**: Numeric strings with exponents or magnitudes larger than `Number.MAX_VALUE` (e.g. `'1e309'` or `'-1e309'`) overflow IEEE-754 double precision to `Infinity` (`Number('1e309') === Infinity`). All four functions return `false` for these strings—they are not finite, and `isNumeric` only accepts explicit non-finite strings (`'Infinity'`, `'-Infinity'`, `'+Infinity'`, and `'NaN'`, with optional whitespace).
* **Boxed primitives are supported**: `new Number(...)` and `new String(...)` instances behave the same as their primitive counterparts across all four functions.
* **No accidental object/array coercion**: Values that coerce to numbers in loose JavaScript checks (such as single-element arrays like `[1]` or objects with custom `valueOf`/`toString` methods) and values that throw on coercion (`Symbol`, `BigInt`, `Object.create(null)`) all safely return `false`.

## Installation

```bash
npm install --save @toolbuilder/isnumber
```

## Getting Started

```javascript
import { isNumeric, isFiniteNumeric, isNumber, isFiniteNumber } from '@toolbuilder/isnumber'

console.log(isNumeric('1.234')) // true because it looks like a number
console.log(isFiniteNumeric(42.54)) // true
console.log(isNumber('1.234')) // false because it is a string
console.log(isFiniteNumber(-Infinity)) // false
```

### isNumber

Test if n is a number.

Includes Infinities and NaN, does not include strings that look like numbers

Parameters:

* `n` **any** value to test



```javascript
isNumber(1.23) // true
isNumber(Infinity) // true
isNumber(NaN) // true
isNumber('1.23') // false
```

Returns **[boolean][1]** true if is number, false otherwise

### isNumeric

Test if n is a number, or string that parses to a number. Includes infinities and NaN.

Non-finite strings are: 'Infinity', '-Infinity', '+Infinity', and 'NaN'.

Parameters:

* `n` **any** value to test



```javascript
isNumeric(1.23) // true
isNumeric('Infinity') // true
isNumeric(NaN) // true
isNumeric('1.23') // true
isNumeric('hi') // false
```

Returns **[boolean][1]** true if is numeric, false otherwise

### isFiniteNumber

Test if n is a finite number.

Does not include infinities, NaN, or strings that look like numbers.

Parameters:

* `n` **any** value to test



```javascript
isFiniteNumber(1.23) // true
isFiniteNumber(Infinity) // false
isFiniteNumber(NaN) // false
isFiniteNumber('1.23') // false
```

Returns **[boolean][1]** true if is a finite number, false otherwise

### isFiniteNumeric

Test if n is a finite number, or string that parses to a finite number.

Does not include infinities, NaN

Parameters:

* `n` **any** value to test



```javascript
isFiniteNumeric(1.23) // true
isFiniteNumeric('Infinity') // false
isFiniteNumeric(NaN) // false
isFiniteNumeric('1.23') // true
isFiniteNumeric('hi') // false
```

Returns **[boolean][1]** true if is a finite number, false otherwise

[1]: https://developer.mozilla.org/docs/Web/JavaScript/Reference/Global_Objects/Boolean
